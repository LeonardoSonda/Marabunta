# Marabunta Buffet

Página web responsive para Marabunta Buffet, creada con Vite y TypeScript.

## Requisitos

- Node.js 20.19 o posterior
- npm

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
```

El comando `npm run build` comprueba los tipos y genera la versión lista para publicar en `dist/`.

La navegación de escritorio y el menú móvil se conservan. Las fotografías del buffet están marcadas como ilustrativas; se pueden reemplazar por fotos propias cuando estén disponibles.
